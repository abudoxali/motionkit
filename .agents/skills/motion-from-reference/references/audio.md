# الصوت

## أ. مع تعليق صوتي
### إن لم يكن عند المستخدم ملف صوت: اكتب `voice-script.md`
- **الإيقاع:** نحو كلمتين في الثانية. فدقيقة واحدة تحتاج قرابة 120 كلمة.
- **ملف واحد** للفيديو كله، وفقرة لكل مشهد.
- **تعليمات ElevenLabs** بالإنجليزية بين أقواس مربعة، وتتغير مع معنى الجملة:
  - `[calm]` و`[thoughtful]`: للشرح.
  - `[excited]`: للحظة المبهرة.
  - `[curious]`: للسؤال.
  - `[confident]`: للمعلومة.
- **الوقفات:** `...` داخل الجملة ليتنفّس المتكلم، والوقفات الأطول بين الجمل تُكتب في النص نفسه (سطر جديد أو `[pause]`) لأن التسجيل لا يُعدَّل بعد ذلك.
- **الأرقام بالكلمات** («خمسة عشر» لا «15»)، والأسماء الإنجليزية كما تُكتب.
- **في آخر الملف:**
  - الإعدادات المقترحة: صوت واحد للفيديو كله، وأحدث موديل، والسرعة 1.0.
  - يحفظ الملف أينما شاء، ثم يُستورد: `npm run asset:import -- --project <id> --file "<المسار>" --role voiceover`.
- **`script.txt`:** نفس النص بلا تعليمات، وكل سطر فيه = سطر على الشاشة. هذا الملف للتوقيت.

### بعد وصول الملف
- التسجيل هو مصدر التوقيت ويُستخدم كما هو: لا قصّ ولا تسريع ولا إضافة صمت (لا تستخدم `align.py --gap` على تسجيل المالك).
- `npm run voiceover:align -- --project <id> --script "<script.txt>"` يكتب التوقيت في `public/user-assets/<id>/timing/` لهذا المشروع فقط، ويقترح مدة الفيديو ونقاط القطع في الوقفات الطبيعية. التفاصيل في [media.md](media.md).
- إن طلب المالك إيقاعًا أبطأ للقراءة، أطِل المشاهد الصامتة أو اطلب تسجيلًا جديدًا؛ ولا تسرّع الحركة.

## ب. بلا تعليق صوتي (مؤثرات فقط)
- `script.txt` هو النص المكتوب على الشاشة.
- `uv run --no-project python .agents/skills/motion-from-reference/scripts/align.py --script script.txt --wps 2.2 --gap 0.8 --out projects/<id>/timing.json` يعطي كل كلمة وقتًا للقراءة (هنا لا يوجد تسجيل، فـ `--gap` آمن). للعربية الثقيلة أو للمبتدئين: `--wps 1.8`.
- الملف بنفس شكل التوقيت، وخاص بهذا المشروع وحده.

## ج. المؤثرات الصوتية
**المصدر:**
- `sfx.py` (`npm run audio:sfx`): يكتب في `public/user-assets/sfx/` (ثم استوردها للمشروع بـ `asset:import --role sfx`) الملفات التالية: `tick` و`click` و`type` و`pop` و`blip` و`hit` و`impact` و`whoosh` و`swish` و`riser` و`swell` و`shimmer` و`glitch` و`drop` و`pen`.
- `@remotion/sfx`: مفيد منه `whoosh` و`whip` و`mouseClick` و`uiSwitch` و`ding` و`pageTurn` و`shutterModern`. **تجنّب** أصوات الميمز (bruh، وvineBoom...)، إلا إن كان المرجع ساخرًا.

**ربط الحدث بالمؤثر:**
| الحدث على الشاشة | المؤثر |
|---|---|
| نص أو عنصر صغير يظهر | `tick` أو `pop` |
| كتابة نص حرفًا حرفًا | `type` |
| كلمة كبيرة تضرب | `hit` |
| أهم لحظة (مرة أو مرتين في الفيديو) | `riser` ثم `impact` |
| انتقال سريع | `whoosh` |
| حركة كاميرا هادئة | `swish` |
| قلم يرسم خطًا | `pen` |
| إبراز أو اختيار | `blip` أو `click` |
| لمعة أو شرارة | `shimmer` |
| خطأ أو تشويش | `glitch` |
| النهاية | `drop` أو `swell` |

**القواعد:**
- مؤثر لكل **حدث بصري**، لا لكل كلمة.
- **الكثافة:** قريبة من المرجع («onsets per minute» في `report.md`)، وأقل من نحو 20 في الدقيقة إن كان هناك تعليق صوتي.
- **الحجم (`volume`):** من 0.25 إلى 0.45 تحت الصوت، ومن 0.5 إلى 0.8 بلا صوت.
- **الموسيقى:**
  - إن أعطاك المستخدم ملفًا، فاستخدمه.
  - وإلا فولّدها بـ `music.py` بمدة الفيديو، واختر المزاج الأقرب للستايل والموضوع: `calm` للشرح الهادئ، و`tech` للتقنية، و`bright` للمبهج.
  - استوردها (`asset:import --role music`) وضعها في مكوّن المشروع بـ `<MusicBed asset="<id>" duckUnder="<voiceover id>" />`، فتخفت تلقائيًا تحت الكلام.
  - الحجم: من 0.12 إلى 0.2 تحت التعليق الصوتي، ومن 0.35 إلى 0.5 بلا تعليق.
  - تجنّب أن تكون الموسيقى والمؤثرات عالية في نفس اللحظة.
