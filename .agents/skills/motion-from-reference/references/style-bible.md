# قالب STYLE.md

اكتب `STYLE.md` في جذر المشروع بهذه الأقسام. وكل رقم فيه يأتي من التحليل أو من النظر إلى الصور، لا من التخمين.

**مصادر الأرقام:**
- `report.md`: المدة، وطول اللقطات، والقطعات، والحركة، والسطوع، والصوت.
- `palette.json`: الألوان.
- صور `motion/`: 8 إطارات بينها 0.1 ثانية. عُدّ الإطارات من بداية الحركة إلى نهايتها لتعرف مدتها.
- صفحات `sheets/`: التكوين، والخطوط، والعناصر المتكررة.

---

```markdown
# STYLE.md: <اسم الأسلوب في 3 كلمات>

## 1. الإحساس العام
ثلاث جمل: ماذا يشعر المشاهد؟ وما الذي يجعل هذا الفيديو معروفًا من أول نظرة؟

## 2. الألوان
| الاسم | الكود | النسبة تقريبًا | الاستخدام |
|---|---|---|---|
| الخلفية | #...... | ..% | ... |
| النص | #...... | ..% | ... |
| المميز | #...... | ..% | متى يظهر بالضبط |
القاعدة: متى يُستخدم اللون المميز، ومتى لا يُستخدم.

## 3. الخطوط
لكل دور:
- عنوان كبير.
- نص.
- تسمية صغيرة.
- أرقام وكود.

واكتب لكل دور: شكل الخط في المرجع (مثلًا: هندسي ثقيل بلا زوائد، ضيق)، ثم الخط الذي ستستخدمه من Google Fonts، والوزن، والحجم بالبكسل على شاشة 1920×1080، وتباعد الأسطر.

## 4. التكوين
- الهوامش.
- أين يقع النص الرئيسي.
- عدد العناصر في الإطار الواحد.
- كم من الإطار فارغ.
- اتجاه القراءة.

## 5. العناصر المتكررة
كل عنصر يتكرر في المرجع (خطوط، أو أشكال، أو إطارات، أو أيقونات، أو مؤشر، أو شبكة...): شكله بدقة، ومتى يظهر.

## 6. مفردات الحركة
| الحدث | كيف بالضبط | المدة | المنحنى |
|---|---|---|---|
| دخول النص | ... | 0.00s | easeOut... |
| خروج النص | | | |
| إبراز كلمة | | | |
| الانتقال بين المشاهد | | | |
| حركة الكاميرا | | | |
| الرسم أو الظهور التدريجي | | | |

## 7. الإيقاع
- متوسط طول اللقطة.
- عدد القطعات في الدقيقة.
- نسبة السكون.
- كم كلمة تكون على الشاشة في نفس الوقت.
- هل الحركة تتبع الكلام كلمة بكلمة، أم جملة بجملة؟

## 8. الملمس واللمسة الأخيرة
الحبيبات، والتوهج، والظلال، وتعتيم الأطراف، والتدرجات، وضبابية الحركة. ولكل واحد درجة تقريبية، مثلًا: «حبيبات خفيفة جدًا، شفافية 0.06».

## 9. الصوت في المرجع
- هل فيه تعليق صوتي؟ وبأي إيقاع؟
- هل فيه موسيقى؟
- المؤثرات: أي نوع، وكم مرة في الدقيقة (من `report.md`)؟

## 10. افعل / لا تفعل
خمس قواعد لكل منهما تحمي الأسلوب.

## 11. ما لن ننسخه
الشعارات، والنصوص، والصور، والأسماء التجارية الموجودة في المرجع.
```
