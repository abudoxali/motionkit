# Video projects

Create one folder per requested video. Production assets such as `SCRIPT.md`, `STYLE.md`, `SCENES.md`, and storyboards belong here; project-wide progress belongs only in the root `STATUS.md`.

Compositions should reuse `src/motion/presets.ts` and register previewable work in `src/RemotionRoot.tsx`. Owner-provided media stays in ignored `public/user-assets/`.
