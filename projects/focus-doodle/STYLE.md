# Focus Doodle — style specification

This production uses the repository's documented `doodle` direction as visual guidance while creating an original character, environment, staging, and narrative.

## Visual language

- Warm hand-drawn ink (`#3A2A1E`) with imperfect rounded borders and offset shadows.
- Core palette: sky blue `#AFDCF0`, sand `#F1D9AE`, leaf green `#BCDB92`, orange `#F07F2E`, plus restrained task colors.
- A single cut-out character is built from original SVG shapes. Head, eyes, arms, body, and legs move independently.
- The same desk, notebook, phone, bubbles, and environment evolve across the four beats so the result reads as one story rather than four slides.
- Camera-scale and background-color changes move from unstable/close/chaotic to open/calm/resolved.
- Paper speckle, rough outlines, curved paths, and asymmetry reinforce the handmade character without copying reference content or branding.

## Motion rules

- All movement is deterministic and derived from Remotion's frame clock.
- Notifications use staggered spring entrances, secondary floating motion, and pressure-driven shake.
- The decision beat uses anticipation, a broad arm sweep, orbital compression, visual decluttering, and a push toward the chosen notebook.
- The conclusion converts the finished task into a drawn path, sequential check marks, and a growing plant, followed by a stable final hold.
- Main Arabic text stays within an 78px side safe area and uses at least 70px type with 1.38 line height.
- No CSS transitions, CSS keyframe animations, timers, or nondeterministic random values are used.

## Source and rights

The original style documentation in `styles/doodle/` is adapted from the MIT-licensed motion-starter-kit workflow. This video's character, SVG artwork, text, and scene logic are newly authored for MotionKit and use no third-party media, logos, or reference-video frames.
