# Doodle Journey

Warm illustrated storytelling with inked cut-out characters moving through one connected world.

- Palette: `#AFDCF0`, `#F1D9AE`, `#BCDB92`, `#3A2A1E`, `#F07F2E`.
- Motion: character limbs pivot around joints; walk phase follows distance; camera travels in pauses between phrases.
- Composition: persistent landscape, foreground depth by vertical position, captions at the top.
- Use: stories, educational reels, human-centered narration.
- Avoid: copying the upstream story, characters, series identity, voice, or footage.

Playable preview: `Style-doodle`. Source component: `src/motion/styles/StylePreviews.tsx`.
