# Plotter Signal

Technical-explainer direction with a near-black measured grid, a single bright plotted path, and forceful editorial typography.

- Palette: `#101317`, `#F0EDE6`, `#FF7A2F`.
- Motion: 0.4–0.8 second cubic path reveals; large words land decisively; camera moves are rare.
- Composition: generous black space, one dominant signal, sparse supporting labels.
- Use: systems, product architecture, technical ideas, abstract concepts.
- Avoid: copying upstream narration, brand names, diagrams, or footage.
