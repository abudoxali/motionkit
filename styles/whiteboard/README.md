# Whiteboard Logic

Step-by-step explanation in which a marker constructs the diagram while the camera follows the active area.

- Palette: `#F7F7F3`, `#23272E`, `#1E63D6`, `#E0412E`, `#F28C12`, `#2E9B4F`.
- Motion: variable-width drawn lines, calm 0.6+ second camera moves, readable holds after construction.
- Composition: one coherent diagram rather than disconnected slides.
- Use: lessons, processes, diagrams, product walkthroughs.
- Avoid: copying upstream subjects, text, audio, or scene layout verbatim.
